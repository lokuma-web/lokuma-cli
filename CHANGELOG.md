## [1.4.10] - 2026-03-29

### Changed
- `design.py`: switched from blocking `POST /v1/design` to SSE streaming `POST /v1/design/stream`
- Real-time progress bar printed to stderr as each domain completes (10 domains in parallel)
- Progress format: `[████░░░░░░] Visual Style: Calm Minimalism`
- Final `done` event carries the full recommendation — output behaviour unchanged

### Added
- `_post_stream()` client function — parses SSE events, prints live progress, returns final payload
- Domain label map (`_DOMAIN_LABELS`) for human-readable progress output

## Background

`lokuma-cli` is the installer for [Lokuma](https://lokuma.io) — a cloud-based design intelligence skill for AI coding assistants. It replaces the previous local-only `uipro-cli` approach with a thin client that calls the Lokuma cloud API, eliminating the need for local CSV data files and Python dependencies.
